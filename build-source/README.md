# KEEP IN MIND
The project is still in a very early alpha stage. It hitches a lot, has a ton of performance and memory safety issues and doesn't yet fully work.

# BOTS
Bots and their corresponding logic are included in this server build. However, they are very poorly optimized and cause a lot of performance issues and crashes.

# HOW TO PLAY
- Download PUBG 6.0.6.3 from Steam Depots. Open the steam console (Win + R -> steam://open/console) and use the following commands:
- Download content:  download_depot 578080 578081 6844732025739669729
- Download binaries:  download_depot 578080 578082 442406709355752115
- Copy the contents of the Win64 folder in the repository to /TslGame/Binaries/Win64/ in the game files
- Run the RUN_LocalServer.bat batch file and type the URL of the map you want to play, then hit Confirm
- Inject the DLL after the map has loaded
